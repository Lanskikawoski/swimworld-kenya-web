# Swimworld Kenya — Next.js Modernization

A high-performance, modern Next.js (App Router) website for Swimworld Kenya, incorporating modern frontend design standards, Framer Motion transitions, and Tailwind CSS.

## Quick Start (Deploying to Vercel)

### Option 1: Using Vercel CLI (Simplest)
1. Extract this zip file.
2. Open terminal in the extracted directory.
3. Run:
   ```bash
   npx vercel
   ```
4. Follow the interactive prompts and deploy to production with:
   ```bash
   npx vercel --prod
   ```

### Option 2: Using GitHub Web
1. Extract this zip file.
2. Create a new repository on [GitHub](https://github.com/new).
3. Push the files to GitHub:
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/<your-username>/<your-repo>.git
   git push -u origin main
   ```
4. Import the repo in [Vercel](https://vercel.com/new) and click Deploy.

## Local Development
```bash
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000).
